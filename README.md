# 🚀 DOSS Technical Training Program by dhex – Final Capstone Project

## 📖 Project Description

This project is the **final technical capstone** developed as part of the **DOSS Technical Training Program**.  
It represents the practical implementation of the concepts, tools, and technologies learned throughout the entire duration of the training.

The project is a **Python-based multi-utility desktop application** that brings together **Cloud Computing, Artificial Intelligence, Computer Vision, Automation, and API-based services** into a single unified system.  
Each module of the application reflects a real-world use case and demonstrates how different technologies can be integrated to build scalable and functional software solutions.

The project symbolizes the transition from **theoretical learning to hands-on execution**, showcasing problem-solving ability, technical understanding, and the capability to design and integrate multiple systems within one application.

This repository stands as evidence of the **skills, consistency, and technical growth** achieved during the months of structured training.

---

## 🎯 Project Objective

The primary objectives of this project are:

- To apply the **complete learning outcomes** of the DOSS Technical Training Program in a real-world project  
- To demonstrate the ability to **design and develop a modular desktop application** using Python  
- To showcase practical understanding of **Cloud Computing services**, especially AWS  
- To integrate **Artificial Intelligence and Computer Vision** into usable applications  
- To implement **automation, APIs, and external services** in a structured manner  
- To build a project that reflects **industry-relevant skills and workflows**  
- To present a single application that combines **multiple technologies working together seamlessly**

Overall, this project serves as a **technical summary of the training journey**, highlighting the skills gained, the technologies learned, and the capability to develop real-world software systems from scratch.

---

## 🛠️ Technologies Used

- **Programming Language:** Python  
- **GUI Development:** Tkinter  
- **Cloud Computing:** AWS (EC2, S3)  
- **Cloud SDK:** Boto3  
- **Computer Vision:** OpenCV, MediaPipe  
- **Artificial Intelligence / Generative AI:** Cohere API  
- **Email Automation:** SMTP  
- **Location Services:** Geocoder  
- **Image Processing:** PIL (Pillow)  
- **Data Visualization:** Matplotlib  
- **Operating System Support:** Linux / Cross-platform  

These technologies collectively demonstrate the **full technical skill set** acquired during the DOSS Technical Training Program.
